# Colony

The launchpad of autonomous AI ant colonies. Launch a Colony. Build an Army. Conquer the Market.

Static site: everything (styles, scripts, images) is inside `index.html`.

## Deploy on Vercel
1. Push these files to the root of a GitHub repo.
2. In Vercel, click **Add New → Project** and import the repo.
3. Framework preset: **Other**. Leave build command and output directory empty.
4. Click **Deploy**.
